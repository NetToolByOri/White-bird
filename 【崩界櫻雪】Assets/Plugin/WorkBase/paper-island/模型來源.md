# 紙本姓名辨識資源

- ONNX Runtime Web 1.22.0（MIT），隨附授權。
- PP-OCRv5 中文 mobile 文字辨識模型（PaddleOCR，Apache 2.0），使用 RapidOCR 提供的 ONNX 轉換版本。模型字表從 ONNX character metadata 取得，包含繁體字。
- 模型來源：https://www.modelscope.cn/models/RapidAI/RapidOCR/resolve/v3.9.2/onnx/PP-OCRv5/rec/ch_PP-OCRv5_rec_mobile.onnx
- 來源設定：https://github.com/RapidAI/RapidOCR/blob/main/python/rapidocr/default_models.yaml
- PaddleOCR：https://github.com/PaddlePaddle/PaddleOCR
- SHA-256：5825fc7ebf84ae7a412be049820b4d86d77620f204a041697b0494669b1742c5

所有資源封裝於 paddle-assets.js，按需載入。全域字串經普通 script 載入，WASM／模型／worker 由 Blob 與記憶體傳遞；無 CDN 或對外上傳。
